# Contribuciones

¡Gracias por querer contribuir!

## Flujo
1. Crea un branch: `feat/mi-idea`.
2. Asegúrate de pasar linters y tests: `make check`.
3. Abre un Pull Request con descripción corta + ejemplos.

## Estilo
- Python 3.10+
- Tipado (mypy) y `ruff` para lint.
- Commits con mensaje claro (incluye *rationale*).
